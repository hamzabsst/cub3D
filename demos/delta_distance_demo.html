📐 Delta Distance Explained Visually

🎯 What We're Visualizing

The two most important concepts in DDA raycasting:

  • delta_dist_x = How far along the ray to cross one vertical grid line
  • delta_dist_y = How far along the ray to cross one horizontal grid line

🔍 What You're Seeing

🟡 Yellow Segments (Delta X)

Each yellow segment represents delta_dist_x distance along the ray.

Every time you travel this distance, you cross exactly one vertical grid line.

🔵 Cyan Segments (Delta Y)

Each cyan segment represents delta_dist_y distance along the ray.

Every time you travel this distance, you cross exactly one horizontal grid line.

🧠 The Key Insight

Look at how the segments overlap! The DDA algorithm works by always choosing whichever comes next:

  • If the next yellow mark is closer → step horizontally (cross vertical line)
  • If the next cyan mark is closer → step vertically (cross horizontal line)

Example Walkthrough:

Change the ray angle and watch how:

  • Steep angles (close to vertical) = small delta_dist_y, large delta_dist_x
  • Shallow angles (close to horizontal) = small delta_dist_x, large delta_dist_y
  • 45° diagonal = delta_dist_x ≈ delta_dist_y

🎮 How This Makes Games Fast

Instead of checking every pixel along the ray (which could be thousands of checks), DDA only checks at grid intersections. For a typical ray, that's maybe 10-20 checks instead of 1000+!

This is why Doom could run smoothly on 1993 computers!
